### Os Mais Utilizados



##### Os 10 comandos que você precisa memorizar primeiro

##### Se estiver começando ou retomando seus estudos de programação, eu priorizaria estes:



###### git init	Iniciar repositório

###### 

###### git clone	Baixar projeto

###### 

###### git status	Verificar alterações

###### 

###### git add .	Preparar alterações

###### 

###### git commit -m	Salvar alterações

###### 

###### git push	Enviar ao GitHub

###### 

###### git pull	Atualizar projeto

###### 

###### git branch	Listar branches

###### 

###### git switch -c	Criar e acessar branch

###### 

###### git merge	Unir branches


Disponível para consultar sempre que necessário.
